SpearDAT

Independent Engineering Project

A modern C++17 and MATLAB framework for missile aerodynamic analysis, based on publicly released Missile DATCOM methods and source material.

SpearDAT reconstructs and modernises the publicly released Missile DATCOM implementation within a structured C++17 software architecture, while incorporating corrections to identified implementation defects and selected methodological issues.

It provides structured C++ and MATLAB interfaces for defining missile geometry, flight conditions and analysis cases, replacing the legacy card-and-file workflow with automated case preparation and traceable aerodynamic results suitable for preliminary design and simulation workflows.

The implementation is supported by comprehensive software verification and aerodynamic validation against publicly available NASA wind-tunnel datasets.
